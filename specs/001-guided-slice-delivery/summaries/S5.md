# Slice S5 summary: develop-feature pauses after each slice with a committed summary, and open design decisions go to the user

- **Spec:** [requirements.md](../requirements.md) · **Design:** [design.md](../design.md) · **Tasks:** [tasks.md](../tasks.md)
- **Tasks:** T25–T33 (plus plan changes 9acda84, which added T71 and T72 to slice S9, and d5981a1, which added T73–T76 to slice S9)

## What changed and why

Design choices stop being made silently. writing-plans now records a task's reasonable approaches in a `- Decision:` field with pros, cons and a recommendation, and asks the user to choose when the plan is approved (R5.1). When a test-writer or implementer finds an approach the plan left open, it builds nothing and returns `Status: DECISION` (R5.2). develop-feature then pauses that task, asks the user and records the choice as `- Decision: <option> (user | recommended)` with the options kept below it, so summaries can cite them (R5.2, R5.4). Each slice also ends in a **Slice checkpoint** (R4.1–R4.4, R6.1): the main session writes `summaries/S<k>.md` from the new `templates/slice-summary.md` and commits it inside the slice's range. It then shows the reading order first, asks two or three comprehension questions whose answers never gate the go-ahead, and turns any changes asked at the pause into tasks or a plan change the user approves before the next slice starts. A partition session never runs the checkpoint; the main session runs it after the last wave is integrated. With `- **Checkpoints:** pre-approved` in the `tasks.md` header, the summary is still written and committed, but the run goes on without stopping and takes the recommended option of any open decision (R4.5, R5.3). opening-pull-requests builds each slice's pull request description from that summary and rewrites its relative links, because GitHub resolves them against the pull request page (R6.2). T26 was built in the agents session (5895014, cherry-picked as aa4bc15), and T28 and T33 in the templates/delivery session (b9f353c → 236541d, b4bd0ad → 030a5e3). The rest was built in the main line.
