## What changed and why

The plugin now learns from its own runs. A new agent, `process-reviewer` (Sonnet, high effort), reads the flow record and returns an `IMPROVEMENT NOTES` report: one note per pattern, each with its evidence and the skill or agent to change (R7.1, R1.1). The record covers review rounds, escalations, rethinks, blocked subagents, gate events and user corrections. The agent is read-only twice over: its tools have no Edit or Write (T43), and the role hooks deny its edits and commits and restore any file it changes (T42). Notes must not carry the project's code, secrets or personal data (R7.3).

A new script, `hooks/scripts/improvement_notes.py`, saves the notes. It reads them on stdin, scrubs them and appends one dated entry, tagged with project, feature and scope, to `<Claude config>/konundrm-eng/improvements.md`, a single file shared by every project (R7.2). That path is fixed: the project and feature names only go into the content, each on one line, so a hostile name cannot move the file (T44). Appending never changes earlier bytes (T45). When the central file cannot be written, the entry goes to `specs/<NNN-slug>/improvement-notes.md` and the CLI warns (R7.4, T48, T49).

Scrubbing is the slice's security core (T46, T47, T57–T59; R7.3), because the file is shared across projects:
- **Code:** the notes are kept only up to the first line that may start code. That means a backtick or tilde fence behind any indentation, list or quote markers, a possible HTML block opener, indented code, or a tab before the content. That line and everything after it become `[rest omitted: it may contain code]`.
- **Secrets:** every `secret_patterns` match is redacted, including PEM private keys of any type (DH, X25519 and the rest), from the BEGIN line to the END line.
- **E-mails:** every e-mail address is redacted, in linear time.

Finally, develop-feature dispatches the process-reviewer at every Slice checkpoint (after the summary commit, also when checkpoints are pre-approved) and once more in Phase 4 for the whole feature. It pipes the report to the script and tells the user when the notes fell back to the feature folder. It never changes the plugin on the strength of the notes (R7.5, T50).

- T57 blocked after three failed spec reviews, each finding a new CommonMark construct (a list marker on an earlier line, paragraph-text openers, lazy continuation, HTML blocks) that turned scrub's "close" into an "open". The recorded options:
  - A: accept the listed forms and plan HTML blocks as a separate task;
  - B: one more fix round that treats any possible HTML block opener as making later blocks unsure;
  - C: change the design: drop everything from the first fence-like line, or use a real CommonMark parser (a new dependency).

  → **C without a parser: keep the notes only up to the first line that may start code, keeping the attempt's work** (recommended). The main session acted as rethinker, because neither session had the rethinker agent loaded. This counts as T57's one escalation.
- Three T47-era tests asserted that prose after a code block survives: keep them | change them to the new rule → **change them** (recommended)
- T57 round 4 found narrow leaks (a whitespace-only line made of Unicode spaces, a tab-column reading difference): accept them as residual risk | one more small fix round → **one more round; if it still fails, the main session decides** (recommended)
- T57 round 5 found two narrow leaks (a tab after a list marker inside spaced nested quotes; U+2028/U+2029 between inline backtick runs). The choice: keep iterating | one last round of blunt fixes → **one last round: any tab in the indentation-and-marker prefix starts code, and no inline-span exception on a line holding a splitlines-only separator. Any later finding becomes a recorded residual risk.** Round 6 passed (recommended).
- T48's subject was 80 characters: keep it | shorten it at cherry-pick → **shorten it** (recommended; options reconstructed)
- Where T57's design change lands: a separate docs commit | T57's integrated commit → **T57's commit rewrites design.md's first Threats row** (recommended; options reconstructed)
