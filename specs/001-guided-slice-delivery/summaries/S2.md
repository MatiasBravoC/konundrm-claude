## What changed and why

A new read-only `rethinker` agent (Opus, effort max) returns NEW APPROACH, ADJUST or PLAN CHANGE when a task keeps failing review (R8.1), and the role hooks deny and restore any file it changes, like the reviewers (R8.5). develop-feature gains a `## Rethink` section: at a task's fifth failed review, or the same review's third failure, it stops the fix rounds, stashes a set-aside attempt by message instead of discarding it (R8.2), waits for the user on a PLAN CHANGE (R8.3), runs every later test-writer and implementer dispatch on Opus high (R1.2), and asks the user after two more failures (R8.4). fix-bug follows the same Rethink with `B1` in place of the task (R8.1, R8.4).
