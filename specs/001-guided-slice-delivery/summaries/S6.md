# Slice S6 summary: the feature ends with a choice of stacked or single pull requests and a feature summary linked from each one

- **Spec:** [requirements.md](../requirements.md) · **Design:** [design.md](../design.md) · **Tasks:** [tasks.md](../tasks.md)

## What changed and why

The end of a feature is no longer fixed to stacked pull requests. When the user approves pushing, develop-feature offers one stacked pull request per slice (the default) or a single pull request with every slice, and opening-pull-requests builds either one (R2.2). With stacked pull requests, `risk:high` goes only on a slice that holds a high-risk task (R2.3). With a single pull request and a high-risk task, the user is warned first that `risk:high` will cover the whole feature, and mutation testing runs locally on all the changed code with the command CI's `risk:high` job runs, or the evidence says why the tool could not run (R2.4). Every description, and the project's PR template, gains a "Commits, one per task" section that takes each task ID from the commit's `Task:` line (R2.5). Phase 4 now writes `specs/<NNN-slug>/summary.md` from the new `templates/feature-summary.md` and commits it in the final `docs(<scope>)` commit, and every pull request links it as a URL pinned to that commit's SHA; branches without a `summary.md` carry no link (R6.3). migrate-code puts each batch on its own `migrate/<slug>-b<k>` branch and tidy-codebase each task on its own `tidy/<slug>` branch, one pull request each (R9.3). Rewriting a pushed pull request's history now always needs the user's explicit yes and goes up with `--force-with-lease`, never a plain `--force`; the old rule allowed only the stacked rebase (R9.4).

How it was built: T34–T37, T39 and T41 in the parallel "delivery" session (branch `claude/p-delivery`), T38 and T40 in the "templates" session. The main session integrated them by cherry-pick, with the check run before each commit: T34 0d05432 → 3546ea9, T35 9bd0220 → d3836bb, T36 b2568cc → 8bea624, T37 a2779f2 → f2f07d9, T38 bb3ad8f (carried into the delivery branch as 0769cfb) → b2cac91, T40 816af60 → 8fb5d49, T41 9a18f32 → 15bca4b.
