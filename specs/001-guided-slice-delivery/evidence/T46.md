## Mutants checked by hand (T47)

mutmut cannot run here (see below), so reviewers injected mutants in memory, without editing the
module, and ran the test file against each. Killed by the T46/T47 tests:

- fences recognised only at column 0; any-length closing fence; inline ``` runs not reduced;
- private key redacted by its header only; private key redacted only when its END line exists;
- each of the 15 other `SECRET_PATTERNS` entries dropped, one at a time;
- `_EMAIL` local part without `.` or `+`;
- the round-1 opener (any line starting with ``` opens a block), the `[ 	]*` CommonMark-only
  opener, and "any later backtick makes it an inline span".

Two mutants survived and each now has its own test:

- `_redact_until_clean` as a single pass → `test_scrub_redacts_a_secret_exposed_by_removing_another`;
- `==` → `>=` in `_opening_fence` → `test_scrub_drops_a_fence_whose_info_string_has_a_longer_backtick_run`.

The security review also ran the property's generator over seeds 0–399 (120,000 texts) with no
failure on the T47 code.
